# Malangotango · A Última Comporta

![[Documentacao/Imagens/capa.png|720]]

A água parou de chegar ao bananal. Malango segue as marcas de uma roda de ferro rio acima, enfrenta os Saposos e descobre por que a última comporta foi fechada.

| Quero… | Por onde começar |
|---|---|
| Jogar | Abra [Malangotango.gbc](Jogavel/Malangotango.gbc) em um emulador de **Game Boy Color**. Aperte **Start**; **A** avança as falas e pula, **B** ataca. |
| Editar no GB Studio | Abra [Malangotango.gbsproj](game/Malangotango/Malangotango.gbsproj). O projeto foi compilado no **GB Studio 4.2.2**. |
| Ler no Obsidian | Escolha **Abrir pasta como cofre** e selecione **segundo-game**, a pasta que contém este README e a pasta oculta `.obsidian`. |
| Ver os desenhos | Os arquivos com camadas e animações estão em `artes/`. As cores e as exportações estão explicadas em [[Documentacao/Arte-e-paletas|Arte e paletas]]. |
